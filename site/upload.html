How do I get a token?
  1. Open GitHub → new fine-grained token (signed in as the repository owner).
  2. Name it e.g. Raid tracker upload and pick an expiry date.
  3. Under Repository access choose Only select repositories → this repository.
  4. Under Permissions → Repository permissions set Contents to Read and write and Actions to Read-only.
  5. Generate token, copy it (it starts github_pat_) and paste it above.

The token only works on this one repository. For another officer, make a separate token the same way and send it to them privately; delete it on GitHub any time to remove their access. Never post a token in Discord or put it in a file on the site.
