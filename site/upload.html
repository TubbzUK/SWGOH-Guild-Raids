How do I get a token?
  1. Open GitHub → new fine-grained token (signed in as the repository owner).
  2. Name it e.g. Raid tracker upload and pick an expiry date.
  3. Under Repository access choose Only select repositories → this repository.
  4. Under Permissions → Repository permissions set Contents to Read and write and Actions to Read-only.
  5. Generate token, copy it with the copy button (it starts github_pat_) and paste it above. Don't screenshot it.

The token only works on this one repository. Never post it in Discord or put it in a file yourself; delete it on GitHub any time to cut off access.

    Set up the officer password

    For the repository owner. Officers then upload with this password instead of a GitHub token. Your token is locked with the password in your browser, and only the locked version is saved to the site.

    1
    Make a new fine-grained token for this: only this repository, Contents: Read and write, Actions: Read-only. Create one.
    2
    At least 12 characters. Four random words works well, e.g. lantern-gravel-otter-sunday. The locked token is public, so a short password could be guessed.
      Changing or cancelling the password

      To change it, create a new token, run this setup again with the new password, then delete the old token on GitHub (Settings → Developer settings → Personal access tokens). Deleting the old token matters: older locked copies stay in the repository's history.

      To stop password uploads completely, delete the token on GitHub.
