# Template for adding a guild

Folders starting with `_` are ignored, so this one never appears on the site.

To add a guild on GitHub:
1. Open `config.yml` here, click the copy button, then go back to `guilds/` → **Add file → Create new file**.
2. Name it `newguild/config.yml` (typing the `/` makes the folder). Use a short name with no spaces.
3. Paste the config, change `guild_name` and `discord_secret`, and commit.
4. Upload that guild's WookieeBot raid and roster files into the new folder.
