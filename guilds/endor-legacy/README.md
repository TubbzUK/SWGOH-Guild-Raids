# Endor Legacy

- **Raid results:** upload into the raid's folder: `order-66/` or `droid-destruction/`.
  (Uploading straight into this folder also works when the file name contains the raid name.)
- **Roster export** (for readiness): upload into this folder. It's recognised and moved to `roster/`.
- **Settings:** `config.yml` (guild name, Discord secret, trend settings).
